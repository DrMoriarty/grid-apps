# Справочник материалов для расчёта подачи (CAM, kiri:moto)

Рабочий справочник для модуля оценки подачи/глубины реза
(`src/kiri/mode/cam/app/fscalc.js`, см. feature-задачи «фаза 1–3»).

Базовая формула (подтверждений не требует, стандарт отрасли):

```
Vf = n × Z × fz        (мм/мин = об/мин × зубьев × мм/зуб)
```

**Статус верификации** (три сессии сетевой проверки). Сессия 1: целевые
страницы производителей (PreciseBits, Amana/ToolsToday, LMT/Onsrud, Curbell,
Kennametal, Aalto) закрыты бот-защитой (HTTP 403), переехали (404) или
тайм-аутят; из веба подтверждён только общий гайд CNCCookbook. Сессия 2
(текущая): подтверждена практика hobby-CNC по алюминию на форуме Carbide 3D
(реальные числа, см. §5), подтверждена достижимость PreciseBits и его
методология (sweet-spot тест, Janka-масштабирование дерева) — но числовые
таблицы chip load PreciseBits прячет за per-product страницами и не отдаёт
текстом; Amana/ToolsToday, Curbell, LMT Onsrud и Aalto по-прежнему
недоступны. Сессия 3: числовых источников не добыто; закрыты три
архивные ветки — в веб-архиве нет снапшотов toolstoday.com/knowledgebase*
(пустой CDX, повторно), routerbitworld.com/Chip-Load-Chart-s (404) и
страниц machining-раздела Curbell (пустой CDX + 404 по прямому адресу);
для wiki.aalto.fi архивная ветка закрыта полностью — CDX по
wiki.aalto.fi/display/ содержит только 302-редиректы без контента, а
живой сайт тайм-аутит и в сессии 3. Поэтому:

- пометка **[W]** — подтверждено веб-источником (со ссылкой на сессию);
- пометка **[E]** — данные из отраслевых справочников (Amana chip load chart,
  Onsrud routing guide, PreciseBits, практика hobby-CNC) по памяти модели;
  численно не перепроверены — перед заливкой в кодовую таблицу желательно
  пройти контрольный список из §7 (там же — актуальный статус каждого пункта).

## 1. Итоговая таблица fz (мм/зуб) по диаметрам

Твёрдосплавные фрезы, хобби-станок, шпиндель 12 000–24 000 об/мин. [E]
(шкала каталогов; для алюминия — перекрёстно подтверждена практикой
Carbide 3D community, см. примечание к строке алюминия и §5).

Зависимость fz(D) **нелинейна**: на малых диаметрах fz ограничена прочностью
инструмента (k_effective выше), на больших — мощностью станка (ниже). Поэтому
основной справочник — таблица по диаметрам; коэффициент k = fz/D — вторичное
приближение (§2).

Примечания к таблице:
- Дерево/МДФ/фанера — значение для up-cut спирали; одно- и двухзубые дают
  сопоставимый fz, отличие в отводе стружки. [E]
- Алюминий: верхняя граница — жёсткий станок с хорошим креплением и смазкой
  (совпадает с металлорежущей шкалой Aalto/Kennametal из черновика);
  нижняя — настольные станки (Shapeoko/Carbide-класс). [W] перекрёстная
  проверка (сессия 2, Carbide 3D community): реальная практика на настольных
  станках — fz 0.001–0.003 in/tooth (0.025–0.076 мм/зуб), минимум от
  опытных участников — 0.001 in/tooth (0.025 мм/зуб) ниже которого стружка
  «сваривается» с фрезой; на Ø6.35 это k ≈ 0.004–0.012 — наша строка Ø6
  (0.035–0.055) лежит внутри наблюдаемого разброса. См. §5.
- Дерево: осторожно с нижней границей на хобби-станках — участники Carbide
  3D сообщают о рабочих chip load 0.0004–0.005 in/tooth (0.010–0.127 мм/зуб)
  на Shapeoko, т.е. заметно ниже каталожной шкалы (каталоги ориентированы
  на полноразмерные роутеры); для настольных станков стартовать от нижней
  трети диапазона и поднимать по тесту. [W, сессия 2]
- Фанера выделена из МДФ: ниже fz из-за клеёных слоёв и пустот (§3).

Годится как стартовая оценка в диапазоне Ø4–12 мм; для Ø<4 мм использовать
табличные значения §1 (линейность ломается). [E]

|---|---|---|

| Твёрдая древесина | 0.025–0.037 | 0.15–0.22 |
| МДФ | 0.027–0.040 | 0.16–0.24 |
| Фанера | 0.020–0.033 | 0.12–0.20 |
| Алюминий (хобби) | 0.006–0.009 | 0.035–0.055 |
| Латунь | 0.005–0.007 | 0.028–0.045 |
| ПОМ | 0.015–0.025 | 0.09–0.15 |
| ПА | 0.013–0.020 | 0.08–0.12 |
| Акрил ПММА | 0.013–0.022 | 0.08–0.13 |

Clamp для мелких диаметров (заменяет черновиковское «0.01–0.02 для всех»): [E]
- металлы (алюминий, латунь): fz_min ≈ 0.01–0.02 при D < 3 мм — верно;
  частично подтверждено практикой Carbide 3D: заявленный минимум для
  алюминия 0.001 in/tooth ≈ 0.025 мм/зуб на рабочем Ø3+ мм; на Ø<3 мм
  наблюдаемые значения идут ниже (0.0004–0.001 in/tooth), т.е. жёсткий
  clamp 0.01–0.02 не противоречит практике, но и не подтверждён напрямую. [W, сессия 2]
- дерево/МДФ/пластик: fz_min ≈ 0.03–0.08 при D < 3 мм — кламп 0.01–0.02
  для них занижен и вызовет подгорание/плавление. [E]

## 3. Глубина за проход (DOC) и врезание (plunge)

Общие правила [W, https://www.cnccookbook.com/feeds-and-speeds/]:
- каталоги производителей дают fz, валидные до DOC = 0.5×D;
- при фрезеровании в полный диаметр (слоттинг) или глубже 2×D параметры
  снижают примерно вдвое;
- при шаге (stepover) меньше 0.5×D действует radial chip thinning: реальная
  стружка тоньше расчётной, и без компенсации подачи фреза «шоркает», а не
  режет (перегрев, налипание — для акрила это прямой механизм плавления на
  чистовых проходах с малым шагом);
- прямое вертикальное врезание заменять на наклонное/винтовое
  (ramp/helical) везде, где позволяет CAM.

| Материал | DOC черновая | DOC чистовая | Plunge (доля от Vf) |
|---|---|---|---|
| Мягкая древесина | 1.0–1.5×D | ≤0.5×D | 0.4–0.6 |
| Твёрдая древесина | 0.75–1.0×D | ≤0.5×D | 0.4–0.5 |
| МДФ | 0.75–1.0×D | ≤0.5×D | 0.4–0.5 |
| Фанера | 0.5–1.0×D | ≤0.5×D | 0.3–0.5 |
| Алюминий (хобби) | 0.25–0.5×D | ≤0.25×D | 0.25–0.33 |
| Латунь | 0.5–1.0×D | ≤0.25×D | 0.25–0.35 |
| ПОМ / ПА | 0.5–1.0×D | 0.25–0.5×D | 0.3–0.5 |
| Акрил | 0.5–1.0×D | ≤0.5×D | 0.25–0.4 |

[E] по всем строкам, кроме ссылок на 0.5×D [W]. Plunge — консенсус hobby-CNC
(1/3–1/2 от боковой подачи; для металлов ближе к 1/3). [W, сессия 2]
частичная поддержка: практика Carbide 3D по алюминию — DOC 0.1 in (2.5 мм)
на Ø6.35 (≈0.4×D) на жёстком настольном станке, т.е. строка «Алюминий
(хобби)» согласуется с наблюдениями; plunge-доли не подтверждались
напрямую.

## 4. Предупреждения по материалам

- **Мягкая древесина** [E]: вырыв волокон на затупленных фрезах; смола
  налипает — чистить/острые фрезы; высокая DOC допустима только с up-cut
  (отвод стружки вверх).
- **Твёрдая древесина** [E]: чиппинг/вырыв на текстурных участках дуба —
  снижать fz; подгорание при заниженной подаче (частая ошибка при
  металлической шкале fz). Направление масштабирования fz по породам —
  через относительную твёрдость (Janka) [W, сессия 2:
  https://www.precisebits.com/tutorials/Guesstimating_Feed_Rates.htm —
  PreciseBits официально масштабирует подачу между породами отношением
  чисел Janka, ограничение: ΔJanka ≤ 400, точнее «от мягкого к твёрдому»].
- **МДФ** [E]: абразивен — только carbide, быстрый износ; мелкая токсичная
  пыль — обязательная вытяжка; подгорание и закоксовка смолы при низкой
  подаче/высоких оборотах.
- **Фанера** [E]: клеёный слой абразивен; пустоты в середине листа — рывки
  подачи (фанера отдельно от МДФ в таблице, fz ниже); up-cut рвёт верхний
  шпон, down-cut душит отвод стружки — для чистого реза с двух сторон
  compression-фреза; для одиночной пластины выбирать, какая сторона важнее.
- **Алюминий 5xxx/6xxx** [W, сессия 2]: налипание (built-up edge) без
  смазки — обязательны mist/воск/taplube; пересечение старой стружки
  (recutting) ведёт к свариванию стружки и поломке — мощный отвод стружки;
  фрезы с полированными канавками, 1–2 зуба на настольных станках (практика
  Carbide 3D: «single flute cutters are by far the easiest tool for
  aluminum on these machines»); ниже минимального chip load (~0.025 мм/зуб)
  стружка «сваривается» с фрезой; на нежёстких станках есть «sweet spot» —
  при слишком низкой подаче материал приваривается к фрезе. Последнее
  (DOC выше 0.5×D на хобби-классе — только с проверенной жёсткостью) — [E].
- **Латунь** [E]: легко режется, СОЖ не обязательна; агрессивный положительный
  передний угол «вырывает» металл — prefer нейтральную геометрию/сниженный
  fz; попутное фрезерование осторожно.
- **ПОМ** [E]: режется отлично, почти без оговорок; следить за отводом
  длинной стружки.
- **ПА (нейлон)** [E]: вязкий, «пружинит» (упругий съём) — острые фрезы,
  ниже обороты/выше подача; влажное поглощение воды меняет размеры.
- **Акрил ПММА** [E]: плавится при низком chipload и/или завышенных
  оборотах — минимальный fz ≈ 0.05–0.08 мм/зуб для Ø3–6; О-flute
  (однозубая, положительная спираль) предпочтительна; сколы на входе —
  не плюмжить вертикально, только ramp; recutting стружки даёт
  повторное приваривание — выдув/вытяжка. Механизм усилен радиальным
  chip thinning на чистовых проходах [W, CNCCookbook].

## 6. Расхождения с черновиком (estimate-velocity.mc)

1. **Дерево и МДФ — главная ошибка черновика: fz занижена в 3–5 раз.**
   Черновик: Ø6 → 0.055–0.085 мм/зуб (k 0.009–0.014). Фактическая шкала
   роутерных chip load для Ø6: мягкое дерево 0.20–0.30, твёрдое 0.15–0.22,
   МДФ 0.16–0.24. Черновик, по-видимому, перенёс металлорежущую шкалу
   (Aalto/Kennametal) на дерево. Последствие: подача в дереве в 3–5 раз
   ниже оптимальной → подгорание МДФ, вырыв/шелушение, перегрев фрезы.
   [W, сессия 2, уточнение] на настольных станках реальная рабочая fz для
   дерева бывает ниже каталожной (0.010–0.127 мм/зуб по Carbide 3D), т.е.
   разрыв с черновиком для хобби-класса меньше 3–5 раз — но направление
   ошибки черновика не меняется: и каталожная, и хобби-практика для дерева
   выше черновиковой металлической шкалы.
2. **Пластик и акрил слиты в одну строку** — надо разделять: ПОМ режется
   агрессивнее (fz 0.09–0.15 при Ø6), акрилу нужен нижний порог fz
   (0.08–0.13 при Ø6) и однозубая O-flute; черновиковские 0.06–0.09 —
   нижняя кромка/занижение, у акрила прямой риск плавления.
3. **Алюминий: черновик по верхней кромке для хобби.** k 0.008–0.012
   соответствует станкам станочного класса (и совпадает с металлорежущей
   шкалой); для настольных станков k 0.006–0.009. Не ошибка, но нужна
   поправка на жёсткость. [W, сессия 2] перекрёстная проверка: наблюдаемая
   практика Carbide 3D fz 0.025–0.076 мм/зуб на Ø3–6.35 → k ≈ 0.004–0.012,
   оба диапазона лежат внутри разброса, чёткие два режима (хобби vs
   станочный) источниками не подтверждаются; наши строки (0.006–0.009 и
   0.008–0.012) остаются рабочей аппроксимацией.
4. **Clamp fz 0.01–0.02 при D<3 мм верен только для металлов**; для
   дерева/пластика минимум 0.03–0.08 (иначе подгорание/плавление). Для
   металлов clamp не противоречит практике, но напрямую не подтверждён.
5. **Черновику не хватает:** DOC как доля D (§3), plunge-доли (§3),
   поправки на chip thinning при stepover < 0.5×D [W], требований по
   смазке алюминия [W, сессия 2 — сваривание стружки/налипание подтверждены
   практикой], разбивки фанера vs МДФ, латуни.
6. Формула Vf = n×Z×fz и сама идея fz ≈ k×D — подтверждены; но k в
   черновике для дерева неверен на порядок масштаба, а линейность на
   малых D должна клампиться по-материальному (п.4).
